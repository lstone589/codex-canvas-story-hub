## What Codex Canvas Provides

Codex Canvas gives writers and roleplay groups a single browser workspace for developing fictional settings. Character records, places, factions, lore, chronology, and relationship data can be managed together instead of being divided among unrelated note-taking tools.

It is also designed for long-running stories: users can read roleplay material continuously, bookmark key story points, compose visual pages, and maintain multiple world projects. The application relies on browser local storage, allowing it to function as a lightweight static web app without a separate everyday-use server.

---

## Core Capabilities

- Maintain rich profiles for characters and roleplay participants.
- Build location pages with expandable structures and parent-child organization.
- Keep factions, lore, and other setting details separated across multiple worlds.
- Track events on a timeline as a story progresses.
- Explore character and story connections through relationship and story graphs.
- Review continuous roleplay archives and bookmark significant moments.
- Design pages using movable, resizable, layered, and text-wrapped components.
- Find material with search, mark favorites, choose themes, and use backup or restore tools.
- Modify text and page components directly within the workspace.
- Manage independent worldbuilding spaces for separate projects.

## Data and Workspace Settings

Project and workspace information is saved in the browser's local storage. This means the data belongs to the browser profile and device used to access the application.

Theme selection, search, favorites, backup, and restore controls are available within the workspace. Make backups of important projects regularly, especially before clearing browser data or switching browser profiles.

## Frequently Asked Questions

### What kinds of users can use Codex Canvas?

Codex Canvas is suited to worldbuilders, authors, roleplay communities, and anyone designing a setting whose characters, locations, events, and stories are connected.

### Is an account needed?

No account requirement is listed in the available project information. Workspace data is handled through browser-based local storage.

### Where does Codex Canvas keep my project data?

The application stores workspace information in local storage for the browser profile and device where it is being used.

### How do I transfer a project to another device or browser?

Use the built-in backup and restore functions when transferring workspace data is supported. Important backup files should also be kept separately.

### Can separate worlds be managed independently?

Yes. Multiple world workspaces are supported, so different settings and roleplay projects can remain separate.

### What can I check if my content disappears?

First confirm that Codex Canvas is open in the original browser profile and on the original device. If a backup exists, restore it and confirm that the intended project has been selected.

### How are new versions obtained?

Open the [latest build](https://lstone589.github.io/codex-canvas-story-hub/) whenever a newer release is published. The available project metadata does not specify a displayed version.
